# Research-demo layout references

Reviewed on November 4, 2026. This is a focused comparison of project presentation and demo structure, not a literature review or assessment of research quality. Original Magnolia layout code was written for this repository; no project template, logo, or page code was copied.

The interactive SAM 2 demo was region-restricted; the accessible research page was reviewed instead. |

## Choices applied to Magnolia

- A descriptive project title and developer line, without an invented paper, affiliation, acceptance, or award.
- Immediate links to the real code, model, evaluation, and documentation.
- A light, compact input/output workspace with readable controls and direct downloads.
- Actual held-out metrics rather than promotional claims.
- A small, secondary botanical reference instead of an oversized educational hero.
- Explicit separation of model predictions and provided annotations.
